# Aplication-of-Cold-Atmosphere-Plasma-in-Glioblastoma
Este trabajo presenta una pequeña introducción al plasma frío atmosférico, planteando la matemática de forma rigurosa y atendiendo a la descripción física; además, se plantean posibles extensiones a futuro, y se aplica el modelo a un tratamiento médico en investigación (contra el cáncer cerebral / glioblastoma)
