# Aplication-of-Cold-Atmosphere-Plasma-in-Glioblastoma
Este trabajo presenta una pequeña introducción al plasma frío atmosférico, planteando la matemática de forma rigurosa y atendiendo a la descripción física; además, se plantean posibles extensiones a futuro, y se aplica el modelo a un tratamiento médico en investigación (contra el cáncer cerebral / glioblastoma).
Los objetivos son claros:
  - Presentar la idea de qué es el CAP (y así tratar otros tipos de plasmas no tan comunes, como los son de componente estelar).
  - Visualizar líneas de campo magnético y eléctrico de chorros de plasma frío, tanto en MATLAB como en el ParaView de Python (extensión de Python de visualización científica).
  - Ver cómo el chorro de plasma incidente provoca la difusión de RONS (Especies Reactivas de Oxígeno Nitrógeno) en el tejido, y cómo estas tendrían la capacidad de combatir con las células cancerígenas.
  - Resolver numéricamente las ecuaciones diferenciales parciales de reacción-difusión en MATLAB para representar visualmente la difusión de RONS y, con ello, la eliminación de tejido cancerígeno.
